# 🎊 청백 운동회 박 터뜨리기 (실시간 참여형 경품 추첨 웹앱)

연수·워크숍 및 중·대규모 행사(40~230명)를 위한 **노트북 방향키(`←`·`→`) + 스마트폰 터치 하이브리드 실시간 박 터뜨리기 추첨 웹앱**입니다.

## ✨ 주요 기능
- **조별전 모드 (오전 20~30개 조 / 최대 230명+)**: 인원 편차 문제를 해결하기 위해 **각 조 상위 `N`명의 기록만 실시간 합산**하여 우승 조 전원에게 당첨 확인증을 발급합니다. (입장 현황 기반 적정 `N`값 자동 추천 포함)
- **개인전 모드 (오후 40~50명 규모)**: **기록 순위 시상** 및 **완주 기준 타수 달성자 랜덤 추첨**을 모두 지원합니다.
- **노트북 & 모바일 동시 지원**: 노트북에서는 `←` / `→` 방향키(꾹 누르기 반칙 방지 적용), 스마트폰에서는 화면 하단 초대형 청·백 버튼 터치로 참여합니다.
- **외부 의존성 제로 (`Node.js` 기본 내장 모듈만 사용)**: 별도 패키지 설치 없이 즉시 실행되며, 오프라인 자체 QR 생성기와 Web Audio API 운동회 효과음이 내장되어 있습니다.

## 🚀 로컬 실행 방법

```bash
node server.js
```
또는 Windows에서 `start-raffle.bat` 파일을 더블클릭합니다.

- **사회자(대형 전광판)**: `http://localhost:3000/host`
- **참가자 화면**: `http://localhost:3000/` (동일 와이파이에서는 전광판의 QR코드 스캔)

## ☁️ 외부 인터넷 배포 (행사장에서 LTE/와이파이 무관 접속 시)
GitHub 저장소를 무료 클라우드 서비스(Render, Railway 등)에 연결하면 별도 설정 없이 바로 동작합니다.
- **Build Command**: *(비워두거나 `npm install`)*
- **Start Command**: `npm start` (또는 `node server.js`)
